How to use the RDP module

1. Enter your grammar. Each line is one non-terminal's rules: NT -> alt1 | alt2.

2. Enter a test string. Tokens are separated by spaces, or written run-together for single-char grammars (e.g. ab = a b).

3. Click Load & Simulate. The full trace is computed.

4. Use Next / Prev to step through, or Play for auto-playback. Adjust the delay slider.

Parse tree colours: purple = non-terminal, green = matched terminal, orange = currently being expanded, red = backtracked/failed, dashed = ε.

Note: RDP tries alternatives left-to-right. Grammars with left-recursion will cause infinite loops — remove left recursion first.
